Reflectarray with Tapered Hexagonal Grid Design for Microwave Power Transmission

ECE Wireless Power Transmission  |  Spring 2026  |  targeting WiSEE 2026  |  HFSS
Aidan Abrams, Christian Merkt, Michael Harrington, Xuan Lin, Gregory D. Durgin — Georgia Institute of Technology
⇩ open PDF in new tab ⇩ open poster in new tab

Abstract

This paper presents the design, simulation, and array analysis of a circular-patch reflectarray element arranged on a hexagonal grid for space-based microwave wireless power transmission (WPT) at 2.45 GHz. All design parameters are derived from first principles: patch radius from the TM11 cavity resonance condition, substrate thickness from Q-factor bounds, and element spacing from grating-lobe and overlap constraints. The circular patch on a hexagonal 50 mm unit cell achieves a 334° reflection phase range, 52° more than the square-patch square-grid baseline. A passive Gaussian aperture taper (σ = 0.70) applied to the circular aperture yields −24 dB sidelobe level and 99.3% beam efficiency with zero active electronics. The passive design is inherently radiation-hard, exhibiting negligible performance degradation over a 20-year geostationary orbit mission, delivering 18.5 MWh more cumulative energy than the active Chebyshev baseline.

Motivation

Space-based WPT requires a transmit antenna that is simultaneously lightweight, foldable for launch, radiation-tolerant, and capable of precise beam steering. The PaddleSat concept folds a flat reflectarray panel using Miura-origami crease patterns and deploys it in orbit as the transmit aperture for a 2.45 GHz WPT link.

Active phased arrays fail in GEO because accumulated total-ionizing-dose (TID) radiation degrades the semiconductor phase shifters and attenuators over time. A purely passive reflectarray eliminates this failure mode: each printed copper patch reflects an incoming wave with a phase shift set by its physical radius, with no active electronics to degrade.

Element Design from First Principles

Frequency & Substrate

Operating frequency: f = 2.45 GHz (ISM band), λ = 122.4 mm. Substrate: Rogers RO4003C (εr = 3.55, tanδ = 0.0027). Chosen for low loss tangent, low permittivity (larger resonant radius = better fab tolerance), and space-heritage qualification. Qdiel = 1/tanδ = 370 ≫ Qrad ≈ 30–60, so the element is radiation-dominated.

Substrate Thickness

Practical reflectarray constraint 0.01λ ≤ h ≤ 0.05λ yields 1.22 mm ≤ h ≤ 6.12 mm. Chosen h = 3.0 mm (kh = 0.154), balancing phase range against surface-wave coupling. Conductor Qcond = 2249 ≫ Qdiel, so conductor loss is not the limiting mechanism.

Resonant Patch Radius

The dominant TM11 mode resonates when J′1(k0aeff) = 0, giving k0aeff = χ′11 = 1.8412. Physical radius a is found iteratively with the fringing correction until resonance is satisfied. Result: anom = 18.1 mm, fres = 2.437 GHz (within 0.5% of target).

Unit Cell Spacing (Hexagonal)

Two constraints determine spacing dnn:

  • No physical overlap at amax = 22 mm with 1 mm clearance: dnn ≥ 45 mm
  • Grating-lobe suppression at θmax = 40°: dnn ≤ 74.5 mm

Hexagonal lattice with dnn = 50 mm satisfies both with 33% margin, using primitive vectors a1 = (50, 0) mm and a2 = (25, 43.3) mm at 60° separation.

HFSS Unit-Cell Simulation

Simulated in Ansys HFSS using an infinite-array Floquet port with rectangular lattice vectors matching the 50 mm × 43.3 mm bounding box and periodic master/slave boundaries. Seven parametric studies: phase curve, oblique scan stability, bandwidth, substrate loss sensitivity, cross-polarization, manufacturing tolerance, and square-patch baseline comparison.

Fig. 1 — Reflection phase vs. patch dimension at 2.45 GHz. Circular patch on hex grid (left) achieves 334°; square patch on rect grid (right) achieves 282°.
Phase range: 334° (circular/hex) vs. 282° (square/rect) — +52° improvement (+21%). Attributable to the smoother current distribution of the circular geometry reducing stored reactive energy near resonance.

Bandwidth & Oblique Stability

3 dB bandwidth: ~400 MHz (±8%), sufficient for orbital thermal cycling. Resonant frequency shifts <150 MHz across 0–40° incidence range, confirming element stability under off-axis feed illumination.

Cross-Polarization

Circular patch geometry yields >40 dB cross-pol isolation across the full design range (vs. ~25 dB for square patches) — important for satellite applications where antenna attitude is not always controlled.

Manufacturing Tolerance

±0.1 mm variation in patch radius: ±25° phase error. ±0.1 mm variation in substrate thickness: ±10°. Both within standard PCB fabrication tolerances.

Array Configuration & Aperture Taper

Four aperture configurations were evaluated:

  1. Square patch / rectangular grid / rectangular boundary (Zhang et al. baseline)
  2. Circular patch / rectangular grid / circular boundary
  3. Square patch / hexagonal grid / rectangular boundary
  4. Circular patch / hexagonal grid / circular boundary (proposed)

Five amplitude tapers were independently applied: uniform, passive Gaussian (σ = 0.70), Chebyshev radial −25 dB (active), Taylor radial −25 dB (active), Chebyshev separable −25 dB (active). The passive Gaussian taper is realized by grading element sizes so that edge elements reflect less power naturally.

20-Year Mission Degradation Analysis

Active designs using PIN diode attenuators degrade in GEO. Under accumulated TID from a 20-year GEO mission, PIN diode forward voltage increases ~15%, raising insertion loss by ~0.3 dB and causing SLL drift of 0.8–1.7 dB. The passive reflectarray is immune: copper patch radius is set by photolithographic patterning and is invariant under radiation.

Fig. 6 — 20-year GEO degradation model. Passive design (flat line) maintains −24 dB SLL throughout. Active designs drift 0.8–1.7 dB.

The circular aperture boundary alone improves SLL from −13.1 dB to −17.7 dB by reducing edge diffraction naturally. Adding the passive Gaussian taper brings SLL to −24.0 dB with 99.3% beam efficiency — surpassing even the best active Chebyshev design on the baseline when beam efficiency is considered.
