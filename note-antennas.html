A few fundamental formulas:

Maxwell's Equations

put in

Speed of Light / Frequency / Wavelength

c = lambda * f
f = c / lambda
lambda = c / f

Half Wave Dipole

Named for having the length of the antenna being half of the wavelength, lambda/2. This is the classic "coat-hanger" antenna that is first shown.

A simple example: the antenna is 30cm long (d), meaning lambda/2 = 30cm => lambda = 60cm => c = lambda * f => 300x10^6 = 60*10^-2 * f, f = 500MHz

This 500MHz is quite close to 433MHz, one of the many ISM bands.

An ISM band — Industrial Scientific Medical — is an UNLICENSED band, meaning that as long as you adhere to power and length specifications, you can transmit whatever you want at any time without paying.

ISM bands are as follows:

  • 6.78 MHz
  • 13.56 MHz
  • 27.12 MHz
  • 40.68 MHz
  • 433 MHz
  • 915 MHz
  • 2.4 GHz (LNA!)
  • 5.8 GHz (Also popular for modern day RFICs!)
  • 24 GHz (Radar!)
